Title
🏎️ F1 AI Race Engineer


Description

An AI-powered Formula 1 race analytics dashboard built using FastF1,
Streamlit, and machine learning techniques.

The system analyzes real F1 telemetry,
race strategy, tyre degradation, weather conditions,
and driver performance.
Features
✔ Real FastF1 telemetry
✔ Race analysis
✔ Driver comparison
✔ AI strategy recommendation
✔ Tyre degradation analysis
✔ Race prediction
✔ Interactive dashboard


Tech Stack

Python
Streamlit
FastF1
Pandas
Plotly
Machine Learning
